# CNM brand assets

| File | Use |
| --- | --- |
| `cnm-logo.svg` | **Primary logo** (vector). Used in the website header, footer, admin and pages. Sharp at any size. |
| `cnm-logo-transparent.svg` | Same logo without the charcoal square, for dark backgrounds. |
| `cnm-mark.svg` / `cnm-mark-transparent.svg` | Petal mark only: favicon, app icon, social avatars. |
| `cnm-logo.png` (1404×1602), `cnm-mark.png` (1024×1024) | High-resolution renders of the SVGs for email, Google (Organization logo) and places that don't take SVG. |
| `cnm-group-logo.png`, `cnm-spectra-logo.jpg`, `cnmworx-logo.jpg`, `cnm-foundation-logo.jpg` | Taken from cnm-group.net (raster). |

The SVG logo is a faithful vector redraw of the original CNM Essentials logo, made with CNM's approval so it stays crystal clear at every size. The petal shapes and colours are measured from the original (charcoal `#23221e`, sage `#d3dbce`, yellow `#fbcc39`). The lettering is set in the closest matching typefaces and converted to outlines. If CNM has the designer's master artwork (AI, EPS or SVG), drop it in as `cnm-logo.svg` and rebuild.
